About

A gallery that is not real.

Quiet Rooms exists to show what alih does on an ordinary multi-page site. Every page here is a separate HTML file with a normal link to the next one. There is no router, no framework, and no build step for the pages themselves.

In browsers that support cross-document view transitions, the browser animates between pages on its own; alih only tells it which elements belong together. In other browsers, alih fetches the next page and swaps it in, so the experience stays close.

Use the switch in the corner to compare the two.
